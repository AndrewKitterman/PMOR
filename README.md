# PMOR Dataset Seeds

This repository now contains four deterministic PDE data generators for parametric model order reduction experiments. The default lineup is intentionally split into `2 x 1D` and `2 x 2D` cases:

- `damped_wave_1d`: damped wave equation with parameterized wave speed, damping, and Dirichlet boundary values.
- `burgers_1d`: viscous Burgers equation on a periodic interval with parameterized viscosity and mean level.
- `heat_square`: 2D heat equation on the unit square with parameterized boundary temperatures on all four sides.
- `fisher_kpp_disk`: 2D Fisher-KPP reaction-diffusion equation on a disk embedded in a Cartesian grid.

Each generator writes one training file and one testing file. By default, the first `50` parameter settings become training trajectories and the `51st` parameter setting is reserved as the held-out test trajectory. Every saved rollout covers only the early transient, about `25%` of a conservative steady-state time estimate, so the later steady state is left for downstream prediction models.

## Repository Layout

- `generators/`: standalone Python generators plus shared utilities.
- `docs/`: one markdown file per PDE case.
- `data/`: committed `.npz` datasets generated by the scripts.
- `tests/`: deterministic smoke tests for all four generators.
- `AGENTS.md`: repo conventions for future automated contributors.

## Dataset Format

Every dataset file is a compressed NumPy archive with a flat snapshot axis. Snapshots are concatenated sequentially by parameter setting, which means trajectory `0` comes first in full, then trajectory `1`, and so on.

Common arrays in each `train.npz` or `test.npz`:

- `states`: flattened snapshot tensor of shape `(total_snapshots, ...)`.
- `times`: snapshot-level times aligned with `states`.
- `trajectory_ids`: trajectory index for each snapshot.
- `trajectory_lengths`: number of snapshots in each trajectory.
- `trajectory_offsets`: offsets that recover each contiguous trajectory block.
- `parameter_matrix`: one row per trajectory.
- `parameter_names`: names for the parameter columns.
- `steady_time_estimates`: per-trajectory steady-state time estimate used to truncate the saved history.
- `metadata_json`: JSON blob with equation, solver, and config metadata.
- Grid arrays such as `x`, `y`, and `mask` when applicable.

## Reproducibility

- Parameter tables come from deterministic Latin hypercube samples.
- Random initial conditions are seeded from the case name, base seed, and trajectory index.
- Every solver asserts finite values during time integration.
- The committed datasets were generated with Python `3.14.2`, NumPy `2.4.2`, and SciPy `1.17.1`.

## Regeneration

Run the test suite first:

```bash
python -m unittest discover -s tests -v
```

Regenerate each case:

```bash
python -m generators.generate_damped_wave_1d
python -m generators.generate_burgers_1d
python -m generators.generate_heat_square
python -m generators.generate_fisher_kpp_disk
```

The committed data footprint is roughly `17 MB`, so it stays light enough for version control while still being dense enough for a paper-scale PMOR study.
